# Gordian Knot

![python versions](https://img.shields.io/badge/python-3.9%20%7C%203.10%20%7C%203.11%20%7C%203.12-blue)

## What is this repo?

This repository is for experimenting with matters that are as intricately entangled as a Gordian Knot. The aim is to resolve problems in a clean and novel way, just like cutting through a Gordian Knot.

## Project Organization

```
    ├── .github/               <- GitHub settings.
    │
    ├── data/                  <- Datasets.
    │
    ├── environments/          <- Environment-specific configurations.
    │
    ├── models/                <- Pretrained and serialized models.
    │
    ├── notebooks/             <- Jupyter notebooks.
    │
    ├── outputs/               <- Outputs.
    │
    ├── src/                   <- Python Source code.
    │
    ├── tests/                 <- Test code.
    │
    ├── .dockerignore
    ├── .gitignore
    ├── LICENSE
    ├── pyproject.toml         <- Main project configuration file.
    ├── uv.lock                <- Auto-generated lock file (do not edit manually).
```
